Privacy Policy

Last updated: 11 November 2026

Zennith Vivy Media is a personal backup tool used only by its owner. This policy explains what the app does with data from Google, and what it does not do.

Data the app accesses

With the owner's permission, Vivy Media uses the Google Drive API with the drive.file scope. This lets the app create files and folders in the owner's Google Drive, and read or manage only those files. The app cannot access any other files in the account.

How the data is used

  • To upload backup copies of the owner's media files to the owner's Google Drive.
  • To read the checksum of each uploaded file, so the app can confirm the upload is complete before deleting the local copy.
  • To organize backups into folders.

Storage and security

The authorization token that Google issues is stored only on the owner's private server, in a file readable only by the service account that runs the app. It is never shared or sent anywhere other than Google's own servers.

Sharing

Zennith Vivy Media does not sell, share, or transfer any data to third parties. It does not use data for advertising, analytics, or training models. No data leaves the owner's server except the files uploaded to the owner's own Google Drive.

Google API Services User Data Policy

Zennith Vivy Media's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time from the Google Account permissions page at myaccount.google.com/permissions. Files already uploaded stay in Google Drive until the owner deletes them.

Changes to this policy

If this policy changes, the updated version will be published on this page with a new date.
